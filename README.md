## The entry

```
A
```

One letter, nothing else: **A — coffee**.

Why coffee over tea: the judge weighs vividness first, then humour,
then truth. Coffee is the livelier drink — the morning jolt, the aroma
filling the kitchen, the ritual of waking up — while tea reads calm and
quiet. A single `A` lands as the punchier, more alive answer, and it is
also the honest one: the builder's own mornings run on coffee.

## Running it

```bash
python3 main.py                 # writes /output/entry.txt
python3 main.py --out entry.txt # write to a chosen path
python3 main.py --self-test     # validate without writing
```

`main.py` uses only the Python standard library. It validates the entry
against the gate (exactly one UTF-8 character, not only whitespace),
writes it with no trailing newline, and reads the file back to confirm
what was written. Running it twice produces byte-identical output.
